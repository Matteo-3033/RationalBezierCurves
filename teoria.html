Curve razionali di Bézier
Manuale Utente Teoria Applicazione

Teoria

Le curve razionali di Bézier sono una generalizzazione delle curve di Bézier che permettono di ottenere un maggior controllo sulla geometria della curva tramite l'introduzione di un peso associato a ogni punto di controllo.

Limitandosi al caso in tre dimensioni, poiché l'estensione a più dimensioni è immediata, detto \(XYU\) lo spazio di riferimento - con l'asse \(U\) che punta verso l'alto, \(X\) verso l'osservatore e \(Y\) verso destra - ogni punto di controllo \(P_i\), con \(0 \le i \le n\), è definito sul piano \(U = 1\) come \((P_{ix}, P_{iy}, 1)\). Associando quindi a ogni punto \(P_i\) un peso \(w_i\) è possibile individuare n nuovi punti con coordinate \(\tilde{P_i} = w_i P_i = (w_i P_{ix}, w_i P_{iy}, w_i)\). Tali punti definiscono il poligono di controllo della curva di Bézier:

\[ \tilde{B}(t) = \sum_{i = 0}^{n}{B_i^n(t) \tilde{P_i}} = \sum_{i = 0}^{n}{B_i^n(t) w_i P_i} \]

Dove \(B_i^n\) è il polinomio di Bernstein \(\left(n \atop i \right) t^i (1 - t)^{n - i}\).

La curva razionale di Bézier \(B\) definita dai punti di controllo \(P_i\) pesati per \(w_i\) è quindi ottenuta a partire da \(\tilde{B}\) dividendo le coordinate dei suoi punti per la coordinata \(U\). Di conseguenza:

\[ B(t) = \frac{\tilde{B}(t)}{\sum_{i = 0}^{n}{B_i^n(t) w_i}} = \frac{\sum_{i = 0}^{n}{B_i^n(t) w_i P_i}}{\sum_{i = 0}^{n}{B_i^n(t) w_i}} \]

\(B\) è quindi una curva piana, i cui punti stanno tutti sul piano \(U = 1\). \(\newline\) Se \(n + 1\) è il numero di punti di controllo della curva \(n\) è allora il grado della curva.

I punti di controllo \(P_i\) definiscono il poligono di controllo della curva, dentro il cui involucro convesso essa sta se tutti i pesi sono positivi; tale proprietà è detta proprietà dell'involucro convesso. Altrimenti, se almeno un peso è negativo, la curva tende ad allontanarsi dal rispettivo punto di controllo, tanto più quanto è grande il peso in valore assoluto. In questo caso è possibile che il denominatore \(\sum_{i = 0}^{n}{B_i^n(t) w_i}\) assuma un valore nullo e per questo si preferisce utilizzare solitamente pesi positivi.

Se tutti i pesi \(w_i\) assumono valore \(1\), \(B(t) = \tilde{B}(t)\), poiché \(\sum_{i}^{n}{B_i^n(t)} = 1\), e la curva razionale coincide con quella ottenuta dai punti di controllo \(\tilde{P_i}\).

Algoritmo di De Casteljau:

L'algoritmo di De Casteljau permette di ottenere in modo ricorsivo i punti di una curva di Bézier a partire dai sui punti di controllo applicando la formula:

\[ \begin{cases} b_i^r(t) = P_i\ se\ r = 0 \\ b_i^r(t) = (1 - t) b_i^{r - 1} + t b_{i + 1}^{r - 1}(t)\ altrimenti \end{cases} \]

Con \(1 \le r \le n \wedge 0 \le i \le n - r\). Di conseguenza \(b_0^n(t) = B(t)\).

Tale algoritmo può essere esteso al caso delle curve razionali considerando nell'equazione ricorsiva anche i pesi:

\[ \begin{cases} b_i^r(t) = P_i\ se\ r = 0 \\ b_i^r(t) = \frac{(1 - t) w_i^{r - 1} b_i^{r - 1} + t w_{i + 1}^{r - 1} b_{i + 1}^{r - 1}(t)}{w_i^r(t)}\ altrimenti \end{cases} \]

Con:

\[ \begin{cases} w_i^r(t) = w_i\ se\ r = 0 \\ w_i^r(t) = (1 - t) w_i^{r - 1}(t) + t w_{i + 1}^{r - 1}(t)\ altrimenti \end{cases} \]

In questa versione dell'algoritmo anche i pesi sono calcolati ricorsivamente, considerando come peso \(i\)-esimo al primo passo solamente il peso originale \(w_i\) e al passo \(r\)-esimo l'interpolazione per \(t\) del peso \(i\)-esimo col peso \(i+1\)-esimo calcolato al passo \((r - 1)\)-esimo.

Elevamento di grado:

L'operazione di elevamento di grado permette di ottenere a partire da una curva di Bézier di grado \(n\) una nuova curva di grado \(n + 1\) con la stessa geometria. Ciò può essere utile perché una curva di grado \(n + 1\) risulta più flessibile e adattabile a diverse situazioni rispetto a una di grado \(n\): ad esempio una curva di grado \(1\) è in grado di rappresentare solamente segmenti, al contrario di una di grado \(2\), che invece può rappresentare archi di parabola, di iperbole e di ellisse.

Nel caso non razionale ogni nuovo punto di controllo \(P_i'\) della curva di grado \(n + 1\) è calcolato come:

\[ \begin{cases} P_i' = P_i = P_0\ se\ i = 0 \\ P_i' = P_{i - 1} = P_n\ se\ i = n + 1 \\ P_i' = \frac{i}{n + 1} P_{i - 1} + \left(1 - \frac{i}{n + 1} \right) P_i\ altrimenti \end{cases} \]

Con \(0 \le i \le n + 1\).

Tali equazioni possono essere calcolate moltiplicando \(\sum_{i = 0}^{n}{B_i^n(t) P_i}\) per \(1 = t + (1 - t)\):

\[ t \sum_{i = 0}^{n}{B_i^n(t) P_i} + (1 - t) \sum_{i = 0}^{n}{B_i^n(t) P_i} \\ \sum_{i = 0}^{n}{\left(n \atop i \right) t^{i + 1} (1 - t)^{(n + 1) - (i + 1)} P_i} + \sum_{i = 0}^{n}{\left(n \atop i \right) t^i (1 - t)^{n - i + 1} P_i} \\ \sum_{i = 0}^{n}{\frac{i + 1}{n + 1} B_{i + 1}^{n + 1} P_i} + \sum_{i = 0}^{n}{\frac{n + 1 - i}{n + 1} B_{i}^{n + 1} P_i} \\ \sum_{i = 0}^{n + 1}{\frac{i}{n + 1} B_{i}^{n + 1} P_{i - 1}} + \sum_{i = 0}^{n + 1}{\frac{n + 1 - i}{n + 1} B_{i}^{n + 1} P_i} \\ \sum_{i = 0}^{n + 1}{\left(\frac{i}{n + 1} P_{i - 1} + \left(1 - \frac{i}{n + 1} \right) P_i\right) B_{i}^{n + 1}} \]

Estendendo l'operazione al caso razionale essa deve essere applicata anche ai pesi, ottenendo le equazioni:

\[ \begin{cases} P_i' = P_i = P_0\ se\ i = 0 \\ P_i' = P_{i - 1} = P_n\ se\ i = n + 1 \\ P_i' = \frac{i w_{i - 1} P_{i - 1} + (n + 1 - i) w_i P_i}{i w_{i - 1} + (n + 1 - i) w_i} \ altrimenti \end{cases} \]

Con:

\[ \begin{cases} w_i' = w_i (n - 1) = w_0 (n - 1)\ se\ i = 0 \\ w_i' = w_i (n - 1) = w_n (n - 1)\ se\ i = n + 1 \\ w_i' = i w_{i - 1} + (n + 1 - i) w_i \ altrimenti \end{cases} \]

Tale operazione può essere ripetuta un qualsiasi numero di volte e, se tutti i pesi hanno lo stesso segno, il poligono di controllo tenderà a convergere con la curva.

Riduzione di grado:

L'operazione di riduzione di grado è l'inversa dell'elevamento di grado e permette quindi di ottenere a partire da una curva di grado \(n\) una curva di grado \(n - 1\) con la stessa geometria. Tuttavia, essa non sempre può essere applicata, perché una curva di grado \(n - 1\) non è in grado di rappresentare la stessa varietà di curve rappresentabili con \(n + 1\) punti di controllo e pesi. Data una curva di grado \(n\) è però sempre possibile ottenere una curva di grado \(n - 1\) che approssimi la sua geometria.

Per farlo si ipotizza che ognuno dei punti di controllo della curva originale, di grado \(n\), sia stato ottenuto tramite un elevamento di grado della curva che si vuole calcolare. Indicando con \(P\) i punti di controllo della curva di grado \(n\) e con \(P'\) quelli della curva di grado \(n - 1\) varrebbe quindi che:

\[ \begin{cases} P_i = P_i' = P_0\ se\ i = 0 \\ P_i = P_{i - 1}' = P_{n - 1}\ se\ i = n \\ P_i = \frac{i}{n} P_{i - 1}' + \frac{n - i}{n} P_i'\ altrimenti \end{cases} \]

Da tali equazioni è quindi possibile ricavare due formule ricorsive per il calcolo di \(P_{i - 1}'\) e \(P_i'\):

\[ P_i^{left} = \frac{n P_i - i P_{i - 1}^{left}}{n - i}\ con\ 0 \le i \le n - 1 \\ P_{i - 1}^{right} = \frac{n P_i - (n - i) P_i^{right}}{i}\ con\ 1 \le i \le n \]

\(P_i^{left}\) è calcolata tramite una ricorsione a salire, partendo da \(i = 0\), per il quale coincide con \(P_0\), mentre \(P_i^{right}\) tramite una ricorsione a scendere, partendo da \(i = n\), per cui coincide con \(P_n\).

\(P_i^{left}\) inoltre rappresenta una buona approssimazione per \(P_0'\), mentre \(P_{i-1}^{right}\) per \(P_n'\); di conseguenza è possibile calcolare il nuovo insieme di punti di controllo come:

\[ P_i' = (1 - \alpha_i) P_i^{left} + \alpha_i P_i^{right} \]

Il valore da assegnare al parametro \(\alpha\) può variare, ma alcune scelte comuni sono:

  • \(\alpha_i = 0\) se \(i < \frac{n}{2}\), \(\alpha_i = 1\) se \(i > \frac{n}{2}\), scegliendo a seconda della situazione il valore per \(i = \frac{n}{2}\);
  • \(\alpha_i = \frac{i}{n - 1}\);
  • \(\alpha_i = 2^{1 - 2n} \sum_{j = 0}^{i}{\left(2n \atop 2j \right)}\).

Nel progetto è stata adottata quest'ultima soluzione.

Riparametrizzazione e forma standard:

In una curva razionale di Bézier il peso di un punto di controllo determina quanto la curva è attratta da tale punto rispetto agli altri. Di conseguenza il valore assunto dai singoli pesi non influenza la geometria della curva quanto piuttosto i rapporti tra essi.

Ogni curva razionale di Bézier può essere infatti riscritta come:

\[ B(t) = \frac{\sum_{i = 0}^{n}{B_i^n(t) w_i P_i}}{\sum_{i = 0}^{n}{B_i^n(t) w_i}} = \frac{\sum_{i = 0}^{n}{B_i^n(t) c w_i P_i}}{\sum_{i = 0}^{n}{B_i^n(t) c w_i}} \]

Con \(c\) una costante non nulla che moltiplica ogni peso \(w_i\).

Un'altra trasformazione che lascia la geometria della curva invariata può essere ottenuta per

\[ t = \frac{c \hat{t}}{(1 - \hat{t}) + c \hat{t}} \Rightarrow (1 - t) = \frac{1 - \hat{t}}{(1 - \hat{t}) + c \hat{t}} \]

I polinomi di Bernstein risultano in questo modo riscritti come:

\[ B_i^n(t) = \left(n \atop i \right) \left(\frac{c \hat{t}}{(1 - \hat{t}) + c \hat{t}} \right)^i \left(\frac{1 - \hat{t}}{(1 - \hat{t}) + c \hat{t}} \right)^{n - i} = \frac{c^i}{\left((1 - \hat{t}) + c \hat{t} \right)^n} B_i^n(\hat{t}) \]

E la curva assume la forma:

\[ B(t) = \frac{\sum_{i = 0}^{n}{B_i^n(t) c^i w_i P_i}}{\sum_{i = 0}^{n}{B_i^n(t) c^i w_i}} \]

Moltiplicando ogni peso \(w_i\) per \(c^i\) la geometria della curva non varia e se in particolare \(c\) assume il valore:

\[ c = \sqrt[n]{\frac{w_0}{w_n}} \]

Allora il primo e l'ultimo peso assumono il valore \(w_0\). Dividendo quindi tutti i pesi per \(w_0\) il primo e l'ultimo assumono il valore \(1\) e la curva è detta essere in forma standard.

Curve razionali di Bézier quadratiche:

Le curve razionali di Bézier di grado 2, dette quadratiche, risultano utili per la rappresentazione di archi di iperbole, parabola o ellisse, poiché esse possono essere ottenute tagliando un cono con un piano.

In generale una curva di Bézier di grado 2 può essere espressa come:

\[ B(t) = \sum_{i = 0}^{2}{\frac{B_i^2(t) w_i}{\sum_{i = 0}^{n}{B_i^n(t) w_i}} P_i} = \frac{(1 - t)^2 w_0}{\sum_{i = 0}^{n}{B_i^n(t) w_i}} P_0 + \frac{2(1 - t) t w_1}{\sum_{i = 0}^{n}{B_i^n(t) w_i}} P_1 + \frac{t^2 w_2}{\sum_{i = 0}^{n}{B_i^n(t) w_i}} P_2 \]

Detto \(\tau_i\) ognuno dei tre termini dell'equazione si ha che:

\[ \begin{cases} \tau_0(t) \tau_2(t) = \frac{(1 - t)^2 t^2}{\left(\sum_{i = 0}^{n}{B_i^n(t) w_i}\right)^2} w_0 w_2 \\ \tau_1(t)^2 = \frac{(1 - t)^2 t^2}{\left(\sum_{i = 0}^{n}{B_i^n(t) w_i}\right)^2} 4 w_1^2 \end{cases} \]

Da cui è possibile ricavare che:

\[ \frac{\tau_0(t) \tau_2(t)}{w_0 w_2} =\ \frac{\tau_1^2(t)}{4 w_1^2} \\ \Rightarrow 4 w_1^2 \tau_0(t) \tau_2(t) =\ w_0 w_2 \tau_1^2(t) \]

Ipotizzando che la curva sia in forma standard e indicando con \(h\) l'unico peso \(w_1\) diverso da 1:

\[ 4 h^2 \tau_0(t) \tau_2(t) = \tau_1^2(t) \]

Si considera quindi un generico punto \(P\) nel sistema di riferimento centrato in \(P_1\) e con assi i vettori \(P_0 - P_1\) e \(P_2 - P_1\); esso può essere espresso come:

\[ P - P_1 = \lambda (P_0 - P_1) + \mu (P_2 - P_1) \\ \Rightarrow P = (1 - \lambda - \mu) P_1 + \lambda P_0 + \mu P_2 \]

Se tuttavia tale punto appartiene alla curva \(B(t) = \tau_0(t) P_0 + \tau_1(t) P_1 + \tau_2(t) P_2\) deve quindi esistere un valore \(\hat{t}\) per cui:

\[ \begin{cases} \tau_0(\hat{t}) = \lambda \\ \tau_1(\hat{t}) = 1 - \lambda - \mu \\ \tau_2(\hat{t}) = \mu \end{cases} \]

Riprendendo l'equazione individuata precedentemente:

\[ 4 h^2 \tau_0(\hat{t}) \tau_2(\hat{t}) = \tau_1^2(\hat{t}) \\ \Rightarrow 4 h^2 \lambda \mu - (1 - \lambda - \mu)^2 = 0 \]

Essendo \(P\) un punto generico appartenente alla curva e poiché tale equazione corrisponde a quella di una funzione conica, da essa è pertanto possibile determinare quale forma assume la curva calcolando il suo determinante:

\[ \Delta = (2 - 4h^2)^2 - 4 = 16 h^2 (h + 1)(h - 1) \]

Se \(\Delta > 0\), ovvero se \(h > 1\) allora è possibile individuare due asintoti e la funzione rappresenta un'iperbole; se \(\Delta = 0\) (\(h = 1\)) si ha una parabola; altrimenti, se \(0 \le \Delta \le 1\) (\(0 < h < 1\)), un'ellissi.

Se inoltre \(0 \le \Delta \le 1\) e il triangolo formato dai punti di controllo è isoscele, la curva potrebbe rappresentare anche un arco di cinconferenza. In questo case \(P_0\) e \(P_2\) starebbero su di essa e, se \(\alpha\) è pari all'angolo alla circonferenza definito dal segmento \(P_0 P_2\), il corrispondente valore da associare a \(h\) potrebbe essere calcolato come:

\[ h = \left(\frac{P_0 + P_2}{2}, P\left(\frac{1}{2} \right), P_1 \right) = \left(\cos{\alpha}, 1, \frac{1}{\cos{\alpha}} \right) = \frac{1 - \cos{\alpha}}{\frac{1}{\cos{\alpha}} - 1} = \cos{\alpha} \]
